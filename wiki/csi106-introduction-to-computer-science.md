## 2. Mô tả nội dung môn học (Course Description)

This course provides an overview of computer fundamentals. Topics cover all areas of computer science in breadth such as computer organization, network, operating system, data structure , file structure, social and ethical issues. Major Instructional Areas - Introduction to Von Neumann Model and computer components - Numbering system & data representation - Different data types and operations on data - The concepts of computer networking and internet - Operating system - Introduction to basic algorithms and algorithms representation - Introduction to Data structure and File structure - The concepts of database - Software engineering - Computing Security & Ethics - Introduction to Artificial Intelligence (Additional Learning)

## 3. Mục tiêu học tập cốt lõi (Key Learning Outcomes)

- **CLO Name**: CLO Details
- **CLO1**: Understand the subsystems of a computer and describe the role of these components
- **CLO2**: Know how to convert a number from one base to other base( decimal, binary, octal and hexadecimal)
- **CLO3**: Describe how different data type is stored inside a computer as bit patterns and operations on data
- **CLO4**: Describe the layers in netwoking and their relationship
- **CLO5**: Undestand the role of OS in a computer system
- **CLO6**: Define a algorithm and describe tools used to develop algorithms
- **CLO7**: Explain how a program in a high-level language is translated into machine language
