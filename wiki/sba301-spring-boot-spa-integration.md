## 2. Mô tả nội dung môn học (Course Description)

Upon completion of this course students shoud:  1. Understand the followings: • ReactJS concepts for building Front-End application • RESTful API concepts • RESTful API using Spring Boot's built-in features and frameworks • Security features (authentication and authorization) with RESTful API • Handling HTTP requests and responses using Spring Boot's framework • Error handling and exception management in Spring Boot RESTful APIs 2. Be able to: • Build RESTful APIs using Spring Boot's built-in features and frameworks • Implement security features with authentication and authorization • Handle HTTP requests and responses using Spring Boot's framework • Build Front-End application using ReactJS components • Integrate Spring Boot with other technologies and frameworks SQL Server, MongoDB, and ReactJS 3. Be able to work in team and present group's results

## 3. Mục tiêu học tập cốt lõi (Key Learning Outcomes)

- **CLO Name**: CLO Details
- **CLO1**: Understand of the ReactJS library, services, and dependency injection.
- **CLO2**: Apply fetch and catching data in Client-Server Communication
- **CLO3**: Describe RESTful APIs using Spring Boot's built-in features and frameworks
- **CLO4**: Describe the connecting RESTful Web Service with JPA
- **CLO5**: Apply security features such as authentication and authorization
- **CLO6**: Create application with Hibernate and Spring Framework.
- **CLO7**: Apply Spring Data with MongoDB to build an application.
