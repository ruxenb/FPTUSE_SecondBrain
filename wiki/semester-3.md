# Học kỳ 3 - Cấu trúc Dữ liệu, Giải thuật & Cơ sở Dữ liệu

**Summary**: Học kỳ chuyên sâu về tối ưu thuật toán giải quyết bài toán và thiết kế hệ thống lưu trữ cơ sở dữ liệu quan hệ SQL.

**Sources**: raw/Semester_3

**Last updated**: 2026-09-20

---

Học kỳ 3 trang bị hai công cụ mạnh mẽ nhất của kỹ sư phần mềm:

- [[csd201-data-structures-and-algorithms]]: Danh sách liên kết, Ngăn xếp (Stack), Hàng đợi (Queue), Cây nhị phân (Binary Search Tree, AVL), Đồ thị và các giải thuật tìm kiếm, sắp xếp tối ưu O(n log n) (source: raw/Semester_3/CSD201_Data_Structures_and_Algorithms_Cấu_trúc_dữ_liệu_và_giải_thuật.md).
- [[dbi202-database-systems]]: Lý thuyết cơ sở dữ liệu quan hệ, chuẩn hóa dữ liệu (1NF, 2NF, 3NF), viết truy vấn SQL phức tạp và transaction ACID.
- [[lab211-oop-with-java-lab]]: Thực hành xây dựng các ứng dụng dòng lệnh Java phức tạp theo chuẩn clean code.
- [[wed201c-web-design]]: Nền tảng giao diện người dùng Web với HTML5, CSS3 và Responsive Design.

## Bước tiếp theo
Kiến thức CSD201 và DBI202 kết hợp chuẩn bị cho sinh viên phát triển ứng dụng Web hoàn chỉnh tại [[semester-4]].
