# Web Application Architecture & MVC Pattern

**Summary**: Kiến trúc ứng dụng web đa tầng hiện đại phân tách rõ ràng giữa Model, View và Controller.

**Sources**: raw/Semester_4/PRJ301_Java_Web_Application_Development_Phát_triển_ứng_dụng_Java_web.md

**Last updated**: 2026-09-20

---

Kiến trúc web phân tán phân định trách nhiệm rõ ràng giữa các tầng:
- **Tầng Client (Front-end):** Trình duyệt web render HTML/CSS/JavaScript.
- **Tầng Server (Back-end):** Xử lý nghiệp vụ (Business Logic) thông qua Controller và Service.
- **Tầng Dữ liệu:** Database lưu trữ lâu dài.
