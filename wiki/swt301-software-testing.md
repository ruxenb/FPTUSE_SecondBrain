# SWT301 - Software Testing & Quality Assurance

**Summary**: Môn học chuyên sâu về quy trình kiểm thử phần mềm, kỹ thuật thiết kế ca kiểm thử hộp đen, hộp trắng và tự động hóa kiểm thử.

SWT301 đào tạo kỹ năng đảm bảo chất lượng phần mềm theo tiêu chuẩn quốc tế ISTQB:

## Kỹ thuật Kiểm thử Hộp đen (Black-box Testing)
- Phân vùng tương đương (Equivalence Partitioning).
- Phân tích giá trị biên (Boundary Value Analysis).
- Bảng quyết định (Decision Table) và chuyển đổi trạng thái (State Transition).

## Kỹ thuật Kiểm thử Hộp trắng (White-box Testing)
- Độ bao phủ câu lệnh (Statement Coverage) và độ bao phủ nhánh (Branch Coverage).
- Phân tích đường đi cơ sở (Basis Path Testing).

## Tự động hóa Kiểm thử
- Unit Test với JUnit trong Java.
- Tự động hóa kiểm thử giao diện Web với Selenium WebDriver.
