PRO192 chuyển đổi tư duy của sinh viên từ lập trình hàm sang mô hình đối tượng thế giới thực:

## 4 Trụ cột OOP Cốt lõi
- **Encapsulation (Đóng gói):** Bảo vệ dữ liệu bằng access modifiers (`private`, `protected`, `public`) và getter/setter.
- **Inheritance (Kế thừa):** Tái sử dụng mã nguồn thông qua từ khóa `extends` và lớp trừu tượng `abstract class`.
- **Polymorphism (Đa hình):** Nạp chồng phương thức (Overloading) và ghi đè phương thức (Overriding) lúc runtime.
- **Abstraction (Trừu tượng hóa):** Định nghĩa hợp đồng hành vi qua `interface`.

## Kỹ thuật Bổ trợ
- Xử lý ngoại lệ với khối `try-catch-finally`.
- Thư viện Java Collections Framework (`ArrayList`, `HashMap`, `HashSet`).
- Nhập xuất file và Serialization.
