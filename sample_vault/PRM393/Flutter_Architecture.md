# Flutter Clean Architecture

Kiến trúc phân tầng cho ứng dụng Flutter chuẩn Desktop:
- **Tầng UI:** Widgets, Screens, Components.
- **Tầng State Management:** [[Provider_Pattern]] quản lý trạng thái.
- **Tầng Service / Contract:** Tương tác với hệ thống file cục bộ và AI.

## Các khái niệm liên quan
- Tham khảo bài viết về [[Provider_Pattern]] để hiểu cách quản lý state.
- Mô hình làm việc nhóm: [[Agile_Scrum]].
