# Học kỳ 3 - Cấu trúc Dữ liệu, Giải thuật & Cơ sở Dữ liệu

**Summary**: Học kỳ chuyên sâu về tối ưu thuật toán giải quyết bài toán, thiết kế hệ thống lưu trữ cơ sở dữ liệu quan hệ SQL, thiết kế web và tiếng Nhật sơ cấp 1.

**Sources**: raw/Semester_3

**Last updated**: 2026-09-21

---

Học kỳ 3 trang bị các công cụ quan trọng bậc nhất của kỹ sư phần mềm:

- [[csd201-data-structures-and-algorithms]]: Danh sách liên kết, Ngăn xếp (Stack), Hàng đợi (Queue), Cây nhị phân (Binary Search Tree, AVL), Đồ thị và các giải thuật tìm kiếm, sắp xếp tối ưu O(n log n) (source: raw/Semester_3/CSD201_Data_Structures_and_Algorithms_Cấu_trúc_dữ_liệu_và_giải_thuật.md).
- [[dbi202-database-systems]]: Lý thuyết cơ sở dữ liệu quan hệ, chuẩn hóa dữ liệu (1NF, 2NF, 3NF), viết truy vấn SQL phức tạp và transaction ACID.
- [[lab211-oop-with-java-lab]]: Thực hành xây dựng các ứng dụng Java theo chuẩn clean code và thiết kế hướng đối tượng.
- [[wed201c-web-design]]: Thiết kế giao diện web responsive với HTML5, CSS3, JavaScript và Bootstrap.
- [[jpd113-elementary-japanese-1]]: Tiếng Nhật sơ cấp 1 (A1.1) - Bảng chữ cái Hiragana, Katakana và giao tiếp cơ bản.

## Bước tiếp theo
Kiến thức CSDL và Thuật toán là điều kiện tiên quyết để sinh viên bước vào [[semester-4]] làm việc với Java Web MVC [[prj301-java-web-development]].
