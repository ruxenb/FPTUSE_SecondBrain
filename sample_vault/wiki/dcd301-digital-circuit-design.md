## 2. Mô tả nội dung môn học (Course Description)

This course provides students with a solid and comprehensive foundation in digital circuit design. It begins with essential concepts such as number systems, logic gates, Boolean algebra, and logic function simplification. Students then advance to designing and implementing combinational and sequential logic circuits, including multiplexers, arithmetic circuits, flip-flops, shift registers, counters, and memory elements. The course also introduces hardware description languages (VHDL/Verilog), FPGA-based implementation, and fundamental principles of digital signal and data processing. Through these topics, students learn how hardware is described at the Register-Transfer Level (RTL) and how it is verified using testbenches and simulation. In addition, the course provides an overview of the Digital IC Design Flow, including: - Specification and Functional Requirements - RTL Design using HDL - Functional Verification and Testbench Development - Logic Synthesis to Gate-Level Netlist - Timing Analysis and Optimization - Implementation on FPGA or placement & routing (for ASIC) - Post-synthesis simulation and sign-off checks The module emphasizes not only technical competence but also professional ethics, social responsibility, and the development of creativity and problem-solving skills. Students apply theoretical knowledge through laboratory exercises, hands-on projects, and real-world design practices.

## 3. Mục tiêu học tập cốt lõi (Key Learning Outcomes)

- **CLO Name**: CLO Details
- **CLO1**: Explain number systems, conversions, codes, and binary arithmetic.
- **CLO2**: Apply Boolean algebra and minimization to design logic circuits.
- **CLO3**: Design and analyze combinational logic circuits.
- **CLO4**: Model and verify logic circuits using HDL.
- **CLO5**: Analyze and design sequential circuits using FSMs.
- **CLO6**: Design and implement registers and counters.
- **CLO7**: Describe memory and PLDs including FPGA resources.
