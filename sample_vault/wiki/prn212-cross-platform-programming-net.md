## 2. Mô tả nội dung môn học (Course Description)

Upon completion of this course students should:  1. Understand the followings:    • C# language for developing .NET applications;    • Fundamental concepts of .NET Platform    • Basic knowledge of  Windows Presentation Foundation in .NET  2. Be able to:    • Develop Cross-platform Desktop applications and support for user experience ( UI & UX ) 3. Be able to work in a team and present group's results

## 3. Mục tiêu học tập cốt lõi (Key Learning Outcomes)

- **CLO Name**: CLO Details
- **CLO1**: Describe about  .NET Core Platform,  and more new features of C# language .
- **CLO2**: Demonstrate about OOP , Generic, Delegate & Event , LINQ and Design Pattern in C#
- **CLO3**: Demonstrate about Windows Presentation Foundation
- **CLO4**: Demonstrate about accessing to the database by Entity Framework ( ORM )
- **CLO5**: Explain about Concurrency programming, Stream I/O
- **CLO6**: Apply Generative AI tools to support software development tasks in .NET
