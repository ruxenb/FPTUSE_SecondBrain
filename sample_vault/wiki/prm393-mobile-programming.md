# PRM393 - Mobile Programming (Lập trình Di động)

**Summary**: Môn học phát triển ứng dụng di động đa nền tảng cho iOS và Android sử dụng Flutter Framework và ngôn ngữ lập trình Dart.

**Sources**: raw/Semester_8/PRM393_Mobile_Programming_Lập_trình_di_động.md

**Last updated**: 2026-09-20

---

PRM393 là môn học công nghệ di động tiên tiến nhất trong chương trình kỹ sư phần mềm FPT:

## Thông tin Chung
- **Mã môn học:** PRM393 (3 tín chỉ, 60 slots học).
- **Hệ thống đánh giá:** Project đồ án (30%), Final Exam (30%), Practical Exam (25%), 3 bài Progress Tests (15%).
- **Tài liệu chính:** *Mastering Flutter* (Kevin Moore, 2025) & *Beginning App Development with Flutter* (Rap Payne, 2019).

## Các Trụ cột Kiến thức Trọng tâm
1. **Ngôn ngữ Dart & Bất đồng bộ:** Làm chủ Dart null safety, Futures, Streams qua [[dart-programming]].
2. **Cấu trúc Giao diện:** Thiết kế giao diện cây widget linh hoạt qua [[flutter-widget-tree]].
3. **Quản lý Trạng thái:** Áp dụng [[provider-pattern]] và kiến trúc đa tầng [[flutter-clean-architecture]].
4. **Điều hướng Màn hình:** Quản lý navigation và deep links qua [[flutter-navigation]].
5. **Dữ liệu & API:** Tích hợp HTTP REST API qua [[flutter-networking-rest-api]] và lưu trữ cục bộ SQLite qua [[flutter-local-storage]].
6. **Kiểm thử Ứng dụng:** Viết Unit test và Widget test qua [[flutter-testing-debugging]].
