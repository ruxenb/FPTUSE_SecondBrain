## 2. Mô tả nội dung môn học (Course Description)

Upon completion of this course students should: 1. Understand the followings: • Data acquisition, data quality, and the end-to-end data handling pipeline • Data wrangling concepts: missing values, data types, normalization, encoding • Exploratory data analysis (EDA) and statistical reasoning (correlation, ANOVA, chi-square) • Visualization principles and data storytelling for different audiences • Dashboarding concepts and Power BI semantic modeling (star schema, relationships, measures) 2. Be able to: • Load data from CSV/Excel/JSON/SQL into Python (Pandas) and export results for reuse • Clean and transform data in Python and Excel/Power Query to prepare analytical datasets • Build effective charts with Matplotlib/Seaborn/Folium and communicate insights • Develop interactive Power BI reports/dashboards and publish to Power BI Service • Apply a simple predictive model (regression) to support data-driven decision making 3. Be able to work in team and present results with reproducible notebooks and dashboards

## 3. Mục tiêu học tập cốt lõi (Key Learning Outcomes)

- **CLO Name**: CLO Details
- **CLO1**: Apply data handling techniques (import, clean, transform, summarize) to prepare datasets for analysis in Python/Excel/Power Query.
- **CLO2**: Communicate insights using data storytelling: select audience-appropriate narratives, annotate visuals, and write concise interpretations.
- **CLO3**: Create clear and accurate visualizations in Python (Matplotlib/Seaborn/Folium), choosing suitable chart types and design best practices.
- **CLO4**: Build interactive dashboards in Power BI using good data modeling (relationships/star schema) and DAX measures, then publish and share responsibly.
