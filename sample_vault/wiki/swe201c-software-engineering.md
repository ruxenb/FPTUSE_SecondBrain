SWE201c định hình tư duy của sinh viên từ người "viết code" thành "kỹ sư phát triển phần mềm chuyên nghiệp":

## Khái niệm Trọng tâm
- **Vòng đời phát triển phần mềm (SDLC):** Từ khảo sát yêu cầu, phân tích thiết kế, cài đặt đến kiểm thử và bảo trì.
- **Phương pháp luận phát triển:** So sánh mô hình truyền thống (Waterfall) và phương pháp phát triển linh hoạt [[agile-scrum]].
- **Mô hình hóa hệ thống với UML:** Use Case Diagram, Class Diagram, Sequence Diagram, Activity Diagram.
- **Quản lý phiên bản:** Sử dụng Git trong làm việc nhóm, chia nhánh (branching) và pull request review.
