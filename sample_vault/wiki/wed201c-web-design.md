# WED201c - Web Design (Thiết kế Web Cơ sở)

**Summary**: Môn học thiết kế giao diện trang web hiện đại với chuẩn HTML5, CSS3, Flexbox, Grid và Responsive Web Design.

**Sources**: raw/Semester_3/WED201c_Web_Design_Thiết_kế_web.md

**Last updated**: 2026-09-20

---

Nền tảng xây dựng trải nghiệm thị giác cho ứng dụng Web:
- Ngữ nghĩa HTML5 (Semantic HTML): `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`.
- CSS3 nâng cao: Flexbox layout, CSS Grid, Transitions và Animations.
- Thiết kế thích ứng (Responsive): Media Queries phù hợp nhiều kích thước màn hình.
