- **Time Allocation:** Study hour (500h)  = 33.75h contact hours (1newslot/week*15week) + 1.5h capstone project defense + 464.75h self-study
- **Pre-Requisite:** o Successfully complete (*) below topics:   - Project Management – PMG201c or PMG202c   - Software Architecture and Design – SWD391 or SWD392   - Software development project - SWP391 o Pass 60% of total credits of selected combo. o Pass OJT202 (not apply to international students) o Pass 80% of total credits (PHE_COM* and OJT excluded) (*): GPA must be greater than or equal to 4.
- **Description:** The capstone project provides students important skills and initial experiences in participating in the software projects. Student can apply knowledges they have learned to the real current projects include: - Experiencing across all project phases: requirement, design, coding, testing and release - Finding out and using the templates and composing documents for each project stage - Using knowledges of technology that have been taught - Having the opportunity to research and apply new technologies - Practicing teamwork and how to interact with colleagues in a project implementation process - Ensuring the proper implementation of quality requirements and schedule - Doing troubleshooting  With the team size of 4-5 members, the output product size are required to be equivalent to 20-25 medium use cases (3-7 transactions for each use case; action buttons on the screen, end user interactions to the software screens/functions or database transactions can be counted as transaction)  The capstone project provides students, working in groups, with a significant project experience in which they can integrate much of the material they have learned in their program, including matters relating to requirements, design, implementation, human factors, professionalism, and project management. Students should be expected to deliver one or several iterations of a software system, along with all artifacts appropriate to the process model they are using. These would likely include  a) Project management Plan (perhaps updated regularly),  b) Software Requirements Specifications (SRS) c) Software Design Documents (SDD) d) Test Plan and other Test Documentation (STD) e) Software package & the user guides (package content, installation guide & user manuals)  All the documents in the project implementation process and the progress reports are required to write in English.
- **StudentTasks:** # Choose appropriate project and form group. # Divide and schedule work among members. # Attend all scheduled meeting with supervisor. # Produce document and product according to project requirement and member work share. # Defend work infront of examination board, showing both project results and individual responsibility. # In case of cheating found, the whole team is not allow to defend. #Students are required to attend at least 80% of scheduled meetings with their supervisor(s) to be eligible for the thesis or capstone defense.
